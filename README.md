# 湖南如法网学习自动化脚本

这是一个用于自动完成湖南如法网(hn.12348.gov.cn)学习任务的Python脚本，支持自动登录、课程获取和智能答题功能。

## ✨ 功能特点

- 🔐 **自动登录系统**：支持验证码识别和自动登录
- 📚 **课程自动获取**：自动识别并获取必修课程和章节内容
- 🧠 **智能答题**：支持单选和多选题的自动答题
- 💾 **答案缓存**：使用Redis存储已答题目，提高后续答题效率
- 🎨 **彩色日志**：直观的彩色日志输出，清晰显示运行状态
- ⏱️ **频率控制**：内置请求间隔控制，避免被封禁
- 🔄 **错误重试**：自动重试失败请求，提高稳定性

## ⚙️ 配置说明

### 百度OCR配置

1. 访问 [百度AI开放平台](https://console.bce.baidu.com/ai-engine/old/#/ai/ocr/app/list)
2. 创建应用并获取API Key和Secret Key
3. 在代码中配置这两个值：

python

```
CLIENT_ID = '您的API_KEY'
CLIENT_SECRET = '您的Secret_KEY'
```



### Redis配置 (可选)

如果需要使用答案缓存功能，需要安装并运行Redis服务器：

bash

```
# Ubuntu/Debian
sudo apt-get install redis-server
sudo systemctl start redis

# CentOS/RHEL
sudo yum install redis
sudo systemctl start redis

# macOS
brew install redis
brew services start redis

# Windows

```



## 🚀 使用方法

1. 克隆或下载本脚本到本地
2. 根据需要配置百度OCR的API密钥(可选)
3. 运行脚本：

bash

```
python rufa_auto_learning.py
```



1. 按照提示输入您的手机号和密码
2. 脚本将自动完成所有学习任务

## 🔄 运行流程

1. **登录验证阶段**
   - 获取验证码图片
   - 使用百度OCR识别验证码
   - 提交登录信息
2. **课程获取阶段**
   - 获取必修课程列表
   - 获取每个课程的章节详情
3. **智能答题阶段**
   - 获取每个章节的题目
   - 尝试从缓存获取正确答案
   - 如果没有缓存，自动尝试所有可能的答案组合
   - 将正确答案存入缓存供下次使用

## ⚠️ 注意事项

1. **请求频率控制**
   - 脚本已内置2秒的答题间隔，避免请求过快
   - 请不要修改等待时间，以免被系统检测为异常行为
2. **百度OCR限制**
   - 每个百度OCR账户每月有1000次免费识别次数
   - 如果次数用尽，需要等待下个月或购买额外次数
3. **账号安全**
   - 脚本不会保存您的密码，所有输入信息仅在内存中使用
   - 建议使用学习专用账号，不要使用重要账号
4. **网络要求**
   - 需要稳定的网络连接，脚本会自动重试失败请求
   - 如果网络不稳定，可能会导致学习进度不完整

## ❓ 常见问题

### Q: 脚本运行后没有反应怎么办？

A: 检查网络连接是否正常，以及是否已正确安装所有依赖库。

### Q: 验证码识别失败怎么办？

A: 可能是百度OCR次数用尽或配置错误，请检查OCR配置是否正确。

### Q: 登录失败怎么办？

A: 请检查用户名和密码是否正确，以及验证码是否被正确识别。

### Q: 答题过程中出现错误怎么办？

A: 脚本会自动重试，如果多次失败，请检查网络连接或稍后再试。
