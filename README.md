湖南如法网学习自动化脚本
这是一个用于自动完成湖南如法网(hn.12348.gov.cn)学习任务的Python脚本，支持自动登录、课程获取和智能答题功能。

功能特点
🔐 自动登录系统，支持验证码识别

📚 自动获取必修课程和章节内容

🧠 智能答题，支持单选和多选题

💾 答案缓存功能，使用Redis存储已答题目

🎨 彩色日志输出，直观显示运行状态

⏱️ 请求频率控制，避免被封禁

安装说明
环境要求
Python 3.6+

Redis (可选，用于答案缓存)

安装依赖
bash
pip install requests beautifulsoup4 redis
配置说明
百度OCR配置
访问 百度AI开放平台

创建应用并获取API Key和Secret Key

在代码中配置这两个值：

python
CLIENT_ID = '你的API_KEY'
CLIENT_SECRET = '你的Secret_KEY'
Redis配置 (可选)
如果需要使用答案缓存功能，需要安装并运行Redis服务器：

bash
# Ubuntu/Debian
sudo apt-get install redis-server
sudo systemctl start redis

# CentOS/RHEL
sudo yum install redis
sudo systemctl start redis

# macOS
brew install redis
brew services start redis
使用方法
克隆或下载本脚本

配置百度OCR的API密钥(可选)

运行脚本：

bash
python script_name.py
按照提示输入手机号和密码

脚本将自动完成所有学习任务

运行流程
登录验证

获取验证码图片

使用百度OCR识别验证码

提交登录信息

课程获取

获取必修课程列表

获取每个课程的章节详情

智能答题

获取每个章节的题目

尝试从缓存获取正确答案

如果没有缓存，自动尝试所有可能的答案组合

将正确答案存入缓存供下次使用

注意事项
请求频率控制

脚本已内置2秒的答题间隔，避免请求过快

请不要修改等待时间，以免被系统检测为异常行为

百度OCR限制

每个百度OCR账户每月有1000次免费识别次数

如果次数用尽，需要等待下个月或购买额外次数

账号安全

脚本不会保存您的密码，所有输入信息仅在内存中使用

建议使用学习专用账号，不要使用重要账号

网络要求

需要稳定的网络连接，脚本会自动重试失败请求

如果网络不稳定，可能会导致学习进度不完整

常见问题
Q: 脚本运行后没有反应怎么办？
A: 检查网络连接是否正常，以及是否已正确安装所有依赖库。

Q: 验证码识别失败怎么办？
A: 可能是百度OCR次数用尽或配置错误，请检查OCR配置是否正确。

Q: 登录失败怎么办？
A: 请检查用户名和密码是否正确，以及验证码是否被正确识别。

Q: 答题过程中出现错误怎么办？
A: 脚本会自动重试，如果多次失败，请检查网络连接或稍后再试。
